배포를 진행합니다. 아래 단계를 순서대로 실행하세요.

## 1. 빌드 검증
- `npm run lint`로 린트 검사 실행
- `npx tsc -b --noEmit`로 타입 검사 실행
- `npm run build`로 프로덕션 빌드 실행
- 오류가 있으면 수정 후 다시 검증

## 2. 커밋
- `git status`로 변경사항 확인
- `git diff`로 변경 내용 확인
- 커밋 메시지 컨벤션:
  - 새 기능: `feat: 기능 설명` (예: `feat: 광고 타겟 학과 및 이벤트 추가, UI 수정`)
  - 버그 수정: `fix: 수정 내용` (예: `fix: 페이지네이션 오류 해결`)
  - 리팩토링: `refactor: 내용` (예: `refactor: 모달 컴포넌트 공용화`)
  - 메시지는 한국어로 작성
- 변경된 파일만 `git add`로 스테이징 후 커밋

## 3. 푸시 & 배포
- `git push origin main`으로 메인 브랜치에 푸시
- Vercel이 자동으로 프로덕션 배포를 진행합니다
- 푸시 완료 후 사용자에게 배포 시작을 알려주세요
